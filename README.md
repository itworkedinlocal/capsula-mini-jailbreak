# Capsula

Утилита для джейлбрейка VK Капсулы Мини на Amlogic A113X. Открывает доступ по SSH/FTP, в стандартный пакет установки включены nano, htop и Entware.
Маруся, музыка и настройки сохраняются.

Работает кросплатформенно на Linux и Windows 64 бита.
Есть резервное копирование, обновление с сохранением пароля и откат.

## Как установить

Распакуйте архив для своей системы целиком, чтобы папка `resources` осталась
рядом с программой. Запустите `capsula` в Linux или `capsula.exe` в Windows
и следуйте подсказкам.

Подключение колонки и установка описаны отдельно:

- [Инструкция для Linux](docs/linux.md)
- [Инструкция для Windows](docs/windows.md)

Бэкапы сохраняются в `~/Capsula` или `%USERPROFILE%\Capsula`.
Сохраните эту папку: она пригодится для восстановления колонки.

## Сборка из исходников

Требуются Go 1.27+ и GNU Make. Python 3.12+ нужен для проверки ресурсов
и упаковки релизов. Команды ниже рассчитаны на Linux:

```sh
make build          # build/capsula
make build-windows  # build/capsula.exe
```

Ядро RAM-среды и вспомогательные программы уже включены в каталог `resources`.
После клонирования репозитория всё необходимое для запуска будет на месте.

```sh
make check-resources
./build/capsula diagnose --offline
```

`make check-resources` проверяет файлы по [`resources.lock.json`](resources.lock.json).
Команда `diagnose --offline` проверяет комплект без подключения колонки.

## Для разработки

Основной код находится в `internal/capsula`, исходники нативных помощников в `native`, скрипты для колонки в `resources`.

```sh
make test       # автоматические тесты
make test-full  # проверка ресурсов и полный набор тестов
make vet
```

Колонка для этих тестов не нужна. Подробности о сборке компонентов в [инструкции разработчика](docs/development.md), об упаковке архивов в [описании релизов](docs/releases.md).
