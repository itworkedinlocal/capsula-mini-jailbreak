# VK Капсула — инструкция

Утилита добавляет доступ к системе колонки по сети (SSH), передачу файлов
и установку дополнительных программ. Маруся, музыка и настройки сохраняются.
Телеметрия VK отключается.

## Что нужно

- Компьютер с Linux 64 бита
- Колонка на Amlogic A113X.
- USB-кабель для передачи данных и штатный блок питания колонки.
- Несколько гигабайт свободного места для резервной копии.

## Запуск

Распакуйте архив целиком и откройте полученную папку в терминале.
Не переносите файл `capsula` отдельно от остальных файлов.

Один раз выполните команды ниже. Если появится запрос пароля `sudo`,
введите пароль вашего пользователя Linux.

```sh
sudo install -m 0644 udev/70-capsula-a113x.rules udev/70-capsula-ram-console.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
```

Запустите программу обычным пользователем, без `sudo`:

```sh
./capsula
```

## Установка

1. Выберите «Установить», затем режим (если не знаете, какой выбирать - вам нужен "простой"). Он создаёт резервную копию
   и выполняет все проверки.
2. По подсказке подключите USB к компьютеру.
   Если появится «Сейчас переподключите Капсулу», отключите USB и подключите снова в тот же разъём. Утилиту перезапускать не нужно.
3. Следуйте подсказкам и задайте пароль для доступа к колонке.
   Пароль при вводе не отображается.
4. Дождитесь завершения записи. Отключайте кабель только по подсказке программы.
5. По окончании отсоедините USB и подключите штатный блок питания колонки.
   Дождитесь загрузки и подключения к Wi-Fi.
6. Введите адрес колонки для проверки доступа. Его можно найти в списке устройств
   роутера. Enter позволяет пропустить проверку и выполнить её позже.

В вопросах `[y/N]` введите `y` и нажмите Enter для согласия.
Enter без ответа или `n` означает отказ. В подменю `0` возвращает назад.
После сообщения о завершении терминал можно закрыть.

## Обновление и удаление

**Обновить:** распакуйте новую версию, запустите её и выберите «Обновить».
Подключайте колонку по подсказкам программы. Пароль сохраняется.
Обновление можно выполнить с другого компьютера.
Если вы вручную меняли файлы джейлбрейка, сначала сохраните свои изменения, обновление заменит эти файлы!

**Удалить джейлбрейк:** выберите «Обслуживание» → «Откат».
Следуйте подсказкам, затем верните колонку на штатный блок питания.
Посторонние файлы сохраняются.

## Остальные пункты меню

- **Проверить** — проверить доступ по сети. Колонка должна работать от штатного
  блока питания и быть в одной сети с компьютером.
- **Entware** — установить дополнительные программы, посмотреть их состояние
  или отключить Entware. Для установки колонке нужен интернет.
- **Обслуживание** — диагностика, полная резервная копия и откат.

Для обычного использования выбирайте простой режим.
Быстрый пропускает резервную копию и часть проверок.
Экспертный предназначен для тех, кто сможет самостоятельно восстановить колонку:
ошибка может привести к потере данных и неработающему устройству.

## Если возникла проблема

- Колонка не находится: отключите штатный блок питания, проверьте команды
  из раздела «Запуск», попробуйте другой USB-кабель или разъём.
- Не проходит проверка по сети: проверьте Wi-Fi, адрес колонки и пароль.
  Ошибка этой проверки не отменяет установку.
- Программа остановилась во время записи: сохраните текст ошибки и обратитесь
  за помощью, прежде чем повторять установку.

Резервные копии и сведения о колонке лежат в папке `Capsula` в домашней папке.
Сохраните её и не публикуйте целиком: там есть личные данные и сведения для доступа.
