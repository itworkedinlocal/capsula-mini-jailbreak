# Подготовка релиза

Релиз собирается из этого репозитория; все необходимые ресурсы уже включены.
Расположение архивов прежних версий, локальные бэкапы и стенды не требуются.

```sh
make check-resources
make test-full
make vet
make release
make release-windows
```

В `dist/` появятся Linux TAR.GZ, Windows ZIP и файлы SHA-256.
Папки `build/`, `dist/` и `.cache/` не входят в историю Git.
Предыдущий одноимённый архив при пересборке
сохраняется в `dist/candidates/` по хэшу.

В Git публикуются исходники, необходимые ресурсы и lock-файлы.
Готовые архивы программы с их SHA-256 прикладываются к GitHub Release.

Перед распространением сторонних компонентов учитывайте условия
из `THIRD_PARTY.md`. В частности, MIT проекта не распространяется на
внешнюю Linux-утилиту `update`.
