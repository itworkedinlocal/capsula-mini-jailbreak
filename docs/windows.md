# VK Капсула — инструкция для Windows

Утилита добавляет доступ к системе колонки по сети (SSH), передачу файлов
и установку дополнительных программ. Маруся, музыка и настройки сохраняются.
Телеметрия VK отключается.

## Подготовка

- Windows 10 или 11, 64 бита, компьютер Intel или AMD.
- Колонка на Amlogic A113X, USB-кабель для передачи данных и штатный блок питания.
- Несколько гигабайт свободного места для резервной копии на компьютере.

Распакуйте ZIP целиком через «Извлечь всё» в Проводнике. Откройте полученную
папку и дважды щёлкните `capsula.exe`. Сохраняйте папку `resources` рядом с ним.
Дополнительные программы и интернет на компьютере не нужны.

## Установка

1. Выберите «Установить», затем режим (если не знаете, какой выбирать - вам нужен "простой"). Он создаёт резервную копию
   и выполняет все проверки.
2. Если Windows запросит разрешение на настройку USB, подтвердите его.
   Дождитесь сообщения о готовности помощника. Пока утилита не предложит
   подключить колонку, оставьте её отключённой от компьютера.
3. По подсказке подключите USB к компьютеру.
   Если появится «Сейчас переподключите Капсулу», отключите USB и подключите снова в тот же разъём. Утилиту перезапускать не нужно.
4. Следуйте подсказкам и задайте пароль для доступа к колонке.
   Пароль при вводе не отображается.
5. Дождитесь завершения записи. Отключайте кабель только по подсказке программы.
6. По окончании отсоедините USB и подключите штатный блок питания колонки.
   Дождитесь загрузки и подключения к Wi-Fi.
7. Введите адрес колонки для проверки доступа. Его можно найти в списке устройств
   роутера. Enter позволяет пропустить проверку и выполнить её позже.

В вопросах `[y/N]` ответьте `y` для согласия. Enter или `n` означает отказ.
В подменю `0` возвращает назад. Окно с результатом закрывается после Enter.

## Обновление и остальные действия

- **Обновить** — установить новую версию с сохранением пароля. Можно выполнять
  с другого компьютера. Изменённые вручную файлы джейлбрейка будут заменены.
- **Проверить** — проверить SSH. Колонка должна работать от штатного блока питания
  и находиться в одной сети с компьютером.
- **Entware** — установить дополнительные программы, посмотреть состояние
  или отключить Entware. Для установки колонке нужен интернет.
- **Обслуживание** — диагностика, резервная копия и откат. Откат возвращает штатные
  файлы и отправку технических отчётов; посторонние файлы сохраняются.

Для обычного использования выбирайте простой режим. Быстрый пропускает бэкап
и часть проверок. Экспертный предназначен для самостоятельного восстановления:
ошибка может привести к потере данных и неработающей колонке.

## Если возникла проблема

- Колонка не найдена: отключите штатный блок питания, проверьте USB-кабель
  и попробуйте другой разъём. Подключайте к компьютеру одну Капсулу.
- Настройка USB не удалась: сохраните сообщение ошибки. Не устанавливайте
  драйвер для случайно выбранного устройства вручную.
- Проверка по сети не прошла: проверьте Wi-Fi, адрес и пароль. Ошибка проверки
  не отменяет установку.
- Программа остановилась во время записи: сохраните сообщение ошибки
  и обратитесь за помощью перед повторной попыткой.

Резервные копии и сведения о колонке находятся в `%USERPROFILE%\Capsula`.
Сохраните эту папку и не публикуйте целиком: она содержит личные данные
и сведения для доступа.
